# Privacy Policy

`fitbit-mcp` is a personal, single-user MCP server. It is not a public service
and does not collect, store, sell, or transmit data to any third party.

- All Google Health API data (activity, heart rate, sleep, SpO2, skin
  temperature, VO2 max, paired devices) is read-only and used solely by the
  repository owner, on their own machine, for their own personal use.
- OAuth tokens are stored locally in the OS credential store (Windows
  Credential Manager via `keyring`) on the owner's own device — never
  uploaded, logged, or shared.
- No data fetched from the Google Health API is transmitted anywhere outside
  the local machine running this server.
- This app is not intended for use by anyone other than its owner. If you
  are not the owner, do not authorize this application against your Google
  account.
